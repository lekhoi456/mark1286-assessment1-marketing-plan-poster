# Section 6 v03 — art and production provenance

Prepared 4 October 2026.

This candidate uses locally authored SVG vector drawings for the five process icons, arrows, cards and lettering. No image model generated or edited the illustration, and no external visual prompt was used. The established marker palette and hand-drawn paper/card treatment are reproduced with editable SVG shapes and the existing Marker Felt / Noteworthy typefaces.

The Green SM logo in the header is the supplied `poster/shared-logo.png` embedded byte-for-byte as a PNG data URI in the SVG. It was not redrawn or altered. SHA-256: `36a99749e3cc9585573fedda5fb1dbcf6a76483872cadc2d0f6651ec95430db9`.

The SVG includes all poster text as native `<text>` elements. The only raster element is the embedded shared logo. Output dimensions: 1800 × 1500. This is a standalone candidate; small-scale visual inspection does not establish A0 print readability or whole-poster fit.
